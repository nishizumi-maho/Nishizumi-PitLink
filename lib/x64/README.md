# MOZA SDK binaries go here

This project links against the official MOZA Racing SDK, which is proprietary and not
redistributed in this repository (see the root [README](../../README.md#getting-the-moza-sdk)).

Place these three files here before building:

- `MOZA_API_C.dll`
- `MOZA_API_CSharp.dll`
- `MOZA_SDK.dll`

They ship with the MOZA Racing SDK, available to registered developers from MOZA.
